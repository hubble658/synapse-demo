# SYNAPSE · statik tanıtım yayını

Bu depo yalnızca SYNAPSE sitesinin **statik, sentetik veriyle çalışan tanıtım derlemesini** barındırır (GitHub Pages).
Backend yok, hesap işlemleri kapalı; firmalar, kişiler ve yayınlar kurgusaldır. Kaynak kod ayrı ve özel depodadır.

Yeniden üretmek için kaynak depoda: `cd frontend && npm run build:statik`, çıktı `frontend/dist-statik/`.
