# Logo dosyaları

Hepsi şeffaf PNG. Zemine göre seçin; `src/components/brand/Logo.tsx` bunu `variant` ile yapar.

| Dosya | Zemin | `variant` |
| --- | --- | --- |
| `synapse-mark.png`, `synapse-logo.png` | Açık (beyaz, gri) | `dark` |
| `synapse-mark-koyu-zemin.png`, `synapse-logo-koyu-zemin.png` | Koyu (lacivert menü, koyu tema) | `light` |
| `synapse-mark-beyaz.png`, `synapse-logo-beyaz.png` | Marka kırmızısı, fotoğraf üstü | `mono` |

Koyu zemin ve beyaz sürümler renkli sürümden üretildi: lacivert ile beyaz yer değiştirdi
(pinler beyaz, içindeki simgeler lacivert), kırmızı korundu. Kaynak bir vektör (SVG) dosyası
gelirse bu sürümler ondan yeniden çıkarılmalı.
